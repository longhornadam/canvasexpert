## Confidence basis (why we treat this as ready for August)

- **Full test suite green:** `py -m pytest api/tests` → **1129 passed, 1 skipped**; the
  engine suite is run at the release checkpoint. This is the confidence bar — not a live
  dress rehearsal, which real Canvas data can only provide once school starts.
- **Machine-enforced contracts** (fail the build on drift, not prose):
  - `test_canvas_mutation_ownership.py` — every Canvas write is inventoried with its exact
    scope + reconciliation, plus the none-label guard (no owner may claim "no reconciliation"
    while actually reconciling).
  - `test_transport_ownership.py` — direct outbound HTTP is confined to a declared owner
    allowlist (closes the GET-side transport-drift hole).
  - `test_repo_privacy_scan.py` — tracked files carry no tokens, JWTs, keys, real emails, or
    personal machine paths (already caught + scrubbed one real home-path leak).
  - The typed read-spine + reconciliation contracts.
- **Safety verified in code** (independent senior audits, 2026-07-19/20): reconciliation
  claims traced to code (all 18 "reconciled" owners true); telemetry privacy enforced by a
  closed allowlist; coordinator imports no mutation owner; benchmark output/cleanup confined
  to disposable temp roots; student-free vs private projections physically separate.

## Accepted beta limitations (documented, not defects)

1. **Per-student override staleness (Batch 7 unit 03).** The mirror stores no override
   projection; the only stale surface is `submissions.cached_due_date` on the Student
   Report "Due date extended to" line, with live fallback outside the ~6h freshness window.
   Low severity; no existing hook repairs it. See `mutation-reconciliation-map.md` family 3.
