# Serve Create’s module picker from the current Course Catalog

Status: **GREEN; completed**

Risk: **medium** - this changes a student-free Create read path but must not affect the live operation/preflight boundary.

Depends on: current `dev` after `111fed3`

## Teacher-visible result

When the Course Catalog’s modules scope is current, the Create module picker opens from its
local course list without a Canvas request. If that scope is absent or not current, the
picker retains the current live Canvas behavior and error response.

## Acceptance criteria

- [ ] `GET /api/modules` returns the existing `{ok, modules:[{id,name}]}` response from
  `course_catalog.read_catalog(course_id)` only when the catalog exists and its `modules`
  scope state is exactly `current`; ordering and module IDs/names come from that scope.
- [ ] On the current-catalog path it makes no `_canvas_get` call. Missing, invalid,
  unavailable, stale, or incomplete catalog/module scope uses the present live endpoint
  path and preserves its Canvas error response.
- [ ] `/api/assignment-groups` remains live and unchanged; no operation preparation,
  write, preflight, template, browser script, catalog schema, or refresh behavior changes.
- [ ] The named acceptance gate below passes.

## Explicit non-goals

- Do not add a Course Catalog assignment-group scope or change the existing assignment-group
  endpoint; that needs a named consumer and schema decision.
- Do not serve a stale/previous catalog optimistically, trigger refresh, add a generic
  catalog adapter, or modify Course Expert browser load order.
- Do not alter any Canvas operation or authoring contract.

## Locked decisions

- The current catalog modules envelope is the sole local authority for this display-only
  picker. Any other state is an honest live fallback, even if records are available.
- Project only existing `id` and `name` fields in the same route response shape; do not
  expose module items or catalog envelope/internal paths.
- Operation adapters continue to resolve placement live for every write. This route affects
  picker display only.
