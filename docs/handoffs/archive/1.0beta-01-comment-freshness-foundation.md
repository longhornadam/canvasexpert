# Give submission comments their own bounded freshness envelope

Status: **GREEN; completed** — commit `6103fca`

Risk: **medium** - adds a private course-level freshness sidecar and typed scope, but does not
change any Canvas write, scheduler cadence, report, or Home consumer yet.

Depends on: commit `14a707d` (accepted 07a typed-read repair)

## Teacher-visible result

No surface changes yet. CanvasExpert gains truthful internal knowledge of when submission
comments were last fetched, instead of treating a newer comment-free delta as comment freshness.

## Acceptance criteria

- [x] A strict, private `submission_comments_state.v1.json` course sidecar records only schema,
      course id, state, last success/attempt timestamps, and sanitized error code.
- [x] A successful comment-inclusive full pass marks the sidecar current; a failed attempted
      comment fetch degrades prior success to stale and never-success to unavailable.
- [x] Delta, focused-assignment, roster, group, and post-write submission refreshes never update
      or claim comment freshness.
- [x] `read_service.PRIVATE_SUBMISSION_COMMENTS` returns the existing normalized submission
      records under the comment sidecar's state/time/generation and honors `max_age_hours`.
- [x] Missing/corrupt sidecar state is unavailable and leaves last-good submission files intact.
- [x] The named acceptance gate passes.

## Explicit non-goals

- Home/Work consumption, report fallback/provenance, atomic manifest repair, write-triggered
  comment invalidation, new scheduler work, or a submission-file schema bump.
- Storing names, avatars, attachments, signed URLs, or new comment fields.

## Locked decisions

- Keep the state outside `_sync.v1.json`; do not change `PASS_NAMES`, watermarks, or mirror v1.
- Follow the existing capability/late-policy sidecar pattern and `_write_document` atomic write.
  Use exact states `current|stale|unavailable` and the existing ISO-Z timestamp format.
- Add `store.read_submission_comments_state` and
  `store.record_submission_comments_state(ok, attempted_at, error_code, root)`; no generic
  registry or abstraction.
- `private_submission_comments` reuses `private_submissions(..., max_age_hours=None)` records,
  but its envelope state/time/generation comes only from the comment sidecar. It never calls
  Canvas and is added to `read_service.read`'s local-scope map.
- In `full_pass`, record failure only when the comment-bearing submission request was attempted;
  record success only after the fetched rows were merged successfully.
