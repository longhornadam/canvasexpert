# PowerGrader Copilot Stage 4: Queue UI Batch Tracker

## Goal

Replace the single generic packet import area with a clear Copilot batch tracker when a session has `copilot_packet.batches`.

Teachers must understand:

- This is one PowerGrader session.
- Each Copilot batch uses a fresh Copilot chat.
- Each batch has exactly three numbered upload files.
- Results are pasted back into the matching batch panel.

## Files To Change

- `api/webui/templates/powergrader_queue.html`
- `api/webui/static/powergrader_queue.js`
- `api/webui/static/powergrader_queue.css`

Do not change backend behavior in this stage except if a tiny response display field is missing from Stage 3.

## Render Behavior

Update `renderPacketPanel(s)`.

If:

```javascript
s && s.copilot_packet && Array.isArray(s.copilot_packet.batches) && s.copilot_packet.batches.length
```

then:

- Show `packetStrip`.
- Hide legacy import box.
- Render Copilot batch tracker.

Otherwise:

- Preserve existing legacy packet/import behavior.

## Batch Tracker Copy

Top copy must include:

```text
This is one PowerGrader session. Do not start a new PowerGrader session for later batches.
For each batch, start a new Copilot chat, upload files 01, 02, and 03, paste the batch prompt, then paste Copilot's JSON back here.
```

Show summary:

```text
Imported 2 of 5 batches. AI suggestions loaded for 48 of 117 students.
```

Compute loaded students as:

```javascript
students.filter(function(st) {
  return st.ai_score !== null && st.ai_score !== undefined || !!(st.ai_feedback || '').trim();
}).length
```

## Batch Card

Each batch card should show:

- `Batch 1 of 5`
- status: `Pending`, `Imported`, or `Partial`
- student count
- token estimate if present
- warnings if present

Controls:

- `Open batch folder`
- `Copy Copilot prompt`
- textarea for JSON
- `Import this batch`

HTML generated by JS may look like:

```html
<div class="pg-copilot-batch" data-batch-id="batch-01">
  <div class="pg-copilot-batch-head">
    <strong>Batch 1 of 5</strong>
```

Use the existing `_esc()` helper for all dynamic strings.

## Copy Prompt

Add delegated click handling:

```javascript
document.addEventListener('click', function(e) {
  var copyBtn = e.target.closest('[data-copy-batch-prompt]');
  ...
});
```

Find the batch by ID in `session.copilot_packet.batches`.

Use:

```javascript
navigator.clipboard.writeText(batch.prompt)
```

If clipboard fails, put the prompt text into the status span or open a small `<textarea>` inside the card. Do not silently fail.

## Import Batch

Add delegated click handling for `[data-import-batch]`.

On click:

1. Find batch ID.
2. Read textarea `[data-batch-results="<batch_id>"]`.
3. If empty, show `Paste Copilot JSON first.`
4. Send:

   ```javascript
   var fd = new FormData();
   fd.append('results', text);
   fd.append('batch_id', batchId);
   fetch('/api/powergrader/session/' + SESSION_ID + '/import-results', {method:'POST', body:fd})
   ```

5. On success, reload session:

   ```javascript
   fetch('/api/powergrader/session/' + SESSION_ID)
   ```

6. Re-render:

   - students
   - progress
   - packet panel
   - current student

7. Show:

   ```text
   Batch 1 imported: 24 AI suggestion(s).
   ```

On validation failure, show backend error plus first two validation errors.

## Do Not Do

- Do not open Copilot automatically.
- Do not create a browser window per batch.
- Do not remove existing generic import support for old sessions.
- Do not tell teachers to start a new PowerGrader session.
- Do not auto-approve AI results. They remain suggestions only.

- Teachers see one batch panel per expected Copilot batch.
- UI clearly says this is one PowerGrader session.
- Each batch has its own import area.
- Batch import reloads the session and updates status.
- Existing non-Copilot sessions still have a usable import area.
