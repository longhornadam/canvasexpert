## Locked operational-log contract

Create `api/operational_log.py`. This is **not** Python's general application logger.
Its only write API is:

```python
emit(
    event: str,                 # constant machine code
    outcome: str,               # ok | blocked | failed | unconfigured
    *,
    duration_ms: int | None = None,
    status_code: int | None = None,
    error_class: type[BaseException] | str | None = None,
    count: int | None = None,
) -> None

tail(max_records: int = 500) -> list[dict]
```

Each JSON-lines record has only these keys when applicable:

`timestamp`, `app_version`, `event`, `outcome`, `duration_ms`, `status_code`,
`error_class`, `count`.

Validation rules:

- reject an unknown keyword; never accept `**context`, message, detail, URL, path,
  payload, headers, model response, name, pseudonym, ID, course, assignment, comment,
  or exception text;
- `event` must be a constant-style lower-case machine code matching
  `[a-z][a-z0-9_.-]{0,63}`; callers pass literals, never user/data-derived strings;
- `outcome` is one of the four values above;
- numeric fields are non-negative integers (`status_code` may be 100–599);
- `error_class` stores only a class name matching `[A-Za-z][A-Za-z0-9_]{0,79}`; when
  given an exception, use `type(exc).__name__`, never `str(exc)`;
- `app_version` comes from `api.__version__`.

Write to `%LOCALAPPDATA%/CanvasExpert/Logs/operations.jsonl` with UTF-8 JSON lines.
Use `logging.handlers.RotatingFileHandler` with `maxBytes=1_048_576`, `backupCount=3`,
and UTF-8 encoding. If `LOCALAPPDATA` is absent, fall back to the OS temp directory, not the
repository or synced workspace. Logging failure must never fail the teacher workflow.

`tail()` skips malformed lines and returns only records that pass the same schema.
There is no API route in this slice; slice 5 consumes it for diagnostics.

## Locked AI boundary

Create `api/ai_transmission.py` with one public send function and two explicit blocked
exceptions:

```python
class TransmissionSafetyBlocked(ValueError): ...
class TransmissionBudgetBlocked(ValueError):
    budget: dict

def score_openrouter_bundle(
    bundle: dict,
    vault,
    rubric_text: str,
    persona: dict,
    *,
    api_key: str,
    model: str,
    feedback_pattern: dict | None,
    output_tokens_per_student: int,
    budget_http_get=None,
    transport=None,              # defaults to openrouter_client.score
) -> dict:
    ...
```

Return:

```python
{
    "results": list,
    "failures": list[tuple[str, Exception]],  # local pseudonym + exception, never logged
    "budget": dict,
    "requested": int,
    "successful": int,
}
```

The function executes in this exact order:

1. Run `feedback_safety.scan_payload(bundle, vault)`. If not green, emit one blocked
   event with counts only, raise `TransmissionSafetyBlocked` with a generic message,
   and do not call budget or transport.
2. Run `openrouter_client.teacher_workflow_budget` against the full bundle using the
   exact persona, feedback pattern, and output-token preset. If not `ok`, emit blocked,
   raise `TransmissionBudgetBlocked`, and attach the budget dict for the existing UI.
3. Preserve current failure isolation: send all text-only students in one request and
   each media-bearing student in its own request.
4. Immediately before **each actual transport call**, scan that exact sub-bundle
   again. A failed sub-bundle scan never reaches transport.
5. Pass verified `model_metadata` from the full budget result into the low-level
   transport. Keep the existing injectable transport seam.
6. Preserve partial success. A failed text group becomes per-student local failures if
   media requests can still proceed. Failed media requests affect only that student.
   If every request fails and no result exists, re-raise the last provider exception
   after emitting a failed event.
7. Emit only one final success/failed event for the whole boundary call with duration
   and numeric counts. Do not log model ID or pseudonyms.

Move the budget UI formatting and failure-to-local-student mapping in
`powergrader/ai_workflow.py` around this result; do not duplicate safety, budget, split,
or transport logic there. Keep privacy-step wording honest and behavior-equivalent.

`openrouter_client.py` remains the low-level provider request builder/parser. Change
the scoring-function wording to say actual scoring is called only by `ai_transmission`;
do not make its request builder dependent on a vault.

After implementation, the only production call to `openrouter_client.score` is inside
`api/ai_transmission.py`. Calls to `teacher_workflow_budget` are allowed only inside that
boundary and the registered estimate endpoint. The estimate endpoint must continue to
construct a synthetic estimate bundle and must never receive submission/vault content.
