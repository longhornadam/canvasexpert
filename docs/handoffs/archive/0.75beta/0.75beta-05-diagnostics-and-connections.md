## Locked diagnostic contract

Create `api/diagnostics.py` with only these public functions:

```python
health_snapshot() -> dict
build_support_bundle(destination: Path) -> Path
```

`health_snapshot()` returns booleans and public version strings, never the values used
to compute them. Use this exact top-level shape:

```json
{
  "app_version": "0.75.0-beta.0",
  "tool_schema_version": 1,
  "python": {"available": true, "version": "3.x.y"},
  "canvas": {"configured": false},
  "workspace": {
    "configured": false,
    "writable": false,
    "catalog_present": false
  },
  "mcp": {"importable": true, "entrypoint_present": true},
  "environment": {
    "proxy_configured": false,
    "tunnel_client_present": false
  }
}
```

Rules:

1. `canvas.configured` means a base URL and credential-store token are present; emit
   neither value and do not call Canvas.
2. `workspace.configured` is false when onboarding has no workspace. Do not silently
   substitute a repository directory.
3. Test writability with a uniquely named empty probe under the configured workspace's
   `_System` directory. Delete the probe in `finally`; if the probe created `_System`,
   remove that directory too when it is still empty. A failed cleanup makes `writable`
   false and emits only an allowlisted operational event.
4. `catalog_present` is a boolean existence check of the canonical Canvas Catalog root.
   Do not count, enumerate, or include course IDs.
5. `proxy_configured` is a boolean over the supported proxy environment-variable names.
   Never include environment values.
6. `tunnel_client_present` checks only for the optional portable
   `<app_root>/tools/tunnel-client.exe`. Do not search PATH or the registry, and do not
   run, download, or install it. Its absence is informational and does not make
   CanvasExpert/MCP unhealthy.
7. No field may contain an absolute path, user name, host name, course/student ID,
   exception string, credential, or environment value.

`build_support_bundle(destination)` creates one ZIP containing exactly:

```text
manifest.json
health.json
operations.jsonl
```

- `manifest.json` contains bundle schema `1`, app version, tool schema version, and a
  UTC creation timestamp.
- `health.json` is the exact result of `health_snapshot()`.
- `operations.jsonl` is a bounded tail from `operational_log.tail()` and is already
  limited to the typed allowlist established in slice 3.
- Sort JSON keys, use UTF-8, and make archive member names deterministic.
- Do not include settings files, vault data, catalog records, receipts, activity data,
  environment values, raw logs, stack traces, provider responses, or local paths.
- Build in a temporary sibling and atomically replace `destination`; delete temporary
  artifacts on all failures.

Add `api/webui/routes/support.py` with exact route `POST /api/support-bundle`. It creates
the ZIP in the canonical temp directory, returns it as a file download, and deletes it
with a Starlette background cleanup after the response. It accepts no request body and no
client-supplied filesystem path.

### Generic stdio configuration

`generic_stdio_config()` returns a copyable configuration using the exact current Python
executable and the absolute MCP script inside the unzipped folder. Do not use `-m` here:
MCP clients launch from unpredictable working directories and cannot discover the `api`
package until the absolute script bootstraps its own folder.

```json
{
  "mcpServers": {
    "canvas-expert": {
      "command": "<resolved-python>",
      "args": ["<app-root>/api/mcp_server/__main__.py"]
    }
  }
}
```

Do not write this object to disk. Do not attempt to discover or merge existing client
configuration files. Do not use `py`, `python`, PATH lookup, a globally installed module,
or an installer-generated location.

### Claude Desktop package

`build_claude_mcpb()` creates `CanvasExpert-0.75.0-beta.0.mcpb`. It is a ZIP-format
MCP Bundle using the current MCPB manifest contract, not the obsolete `.dxt` format.
The bundle contains only:

```text
manifest.json
server/launcher.py
```

Lock these implementation choices:

1. Emit these exact public manifest values; add no optional manifest section:

   ```json
   {
     "manifest_version": "0.3",
     "name": "canvas-expert-read-only",
     "display_name": "Canvas Expert (Read Only)",
     "version": "<api.__version__>",
     "description": "Launches the read-only Canvas Expert MCP server from this computer's unzipped CanvasExpert folder.",
     "author": {"name": "Canvas Expert"},
     "server": {
       "type": "python",
       "entry_point": "server/launcher.py",
       "mcp_config": {
         "command": "<resolved-python>",
         "args": ["${__dirname}/server/launcher.py"],
         "env": {"CANVAS_EXPERT_ROOT": "<absolute-app-root>"}
       }
     },
     "compatibility": {"platforms": ["win32"], "runtimes": {"python": ">=3.14,<4.0"}}
   }
   ```

   Use the official current `manifest_version: "0.3"`; do not use the `0.4` `uv`
   preview. Replace the three angle-bracket placeholders with call-time resolved strings;
   serialize every other value exactly as shown.
2. The manifest's `server.entry_point` is `server/launcher.py`.
3. `mcp_config.command` is the resolved `runtime_paths.python_executable()` value. Its
   args contain the launcher via `${__dirname}`. Its environment sets only
   `CANVAS_EXPERT_ROOT` to the call-time `runtime_paths.app_root()` value.
4. `server/launcher.py` uses only the standard library: resolve and validate the root,
   insert it once at the front of `sys.path`, import `api.mcp_server.server`, and start
   the stdio server through its public entrypoint.
5. Do not copy Canvas Expert source, Python dependencies, settings, credentials, logs,
   paths other than the required app-root value, or student/course data into the
   package.
6. Write both ZIP members with `ZIP_DEFLATED` and fixed member timestamp
   `1980-01-01 00:00:00`. Sort JSON keys and end both UTF-8 text members with one newline.
7. This is a folder-linked extension, not a Windows-installed app or self-contained
   redistribution: the launcher has no third-party dependency of its own, while Canvas
   Expert and its dependencies remain in the teacher's unzipped folder. Say this plainly
   in the package description and page. The page must warn that the generated package
   contains the current local folder path, must be regenerated after moving the folder,
   and should not be shared or uploaded as a team extension.
8. Build the archive with Python's standard `zipfile`/`json` libraries. Do not require or
   invoke the `mcpb` CLI, Node, npm, pip, or any package/Windows installer.

The launcher algorithm is fixed: read `CANVAS_EXPERT_ROOT`; resolve it with
`Path.resolve()`; require `<root>/api/mcp_server/server.py` to be a file; insert `str(root)`
at `sys.path[0]` only when absent; import `run_stdio` from `api.mcp_server.server`; call it
once under `if __name__ == "__main__"`. On missing/invalid root, exit with the constant
message `Canvas Expert folder is unavailable; regenerate this extension.` Do not search
drives, PATH, registry, user profiles, or alternate folders, and do not launch a child
process.

Validate the artifact structurally against the locked version-0.3 fields in the sentinel.
Do not install a validator. If Claude Desktop rejects the structurally valid artifact
during maintainer acceptance, return RED with its user-level error; do not request admin
rights or invent a machine-wide workaround.
