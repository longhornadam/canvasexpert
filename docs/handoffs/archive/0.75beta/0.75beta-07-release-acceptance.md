## Combined risk-seam review

Review only the relevant diff hunks and answer each item explicitly:

1. **Credential/FERPA boundary** — no token, base URL, student/course/user identifier,
   submission, grade, comment, private path, or provider response enters tracked files,
   operational logs, diagnostics, or generated connection artifacts.
2. **Canvas writes** — no new write endpoint, auto-post eligibility change, policy bypass,
   or receipt/idempotency change exists. Canvas client logging records typed outcome data
   only.
3. **AI transmission** — every OpenRouter score/budget request passes the centralized SAFE
   scan first; text batching and media isolation remain intact; failure never leaks raw
   content into logs.
4. **Persistence** — vault, settings, sessions, and routine queue use interprocess locks,
   reload within the lock, and atomic replace. Exceptions do not commit partial state.
5. **MCP** — exactly five read-only tools match schema v1, every course-scoped operation
   passes the shared gate, and no MCP module imports HTTP routes.
6. **Connections/support** — support ZIP has exactly three allowlisted members; MCPB has
   exactly two members; no external client config is written; ChatGPT uses the documented
   outbound tunnel and Canvas Expert stores no tunnel API key.
7. **Runtime/imports** — workspace and executable paths resolve at call time, app version
   has one source, supported entrypoints use one module identity, and local bind remains
   `127.0.0.1`.
8. **Scope** — activity is removed without deleting status/receipts; global CSRF middleware,
   vault encryption, and engine changes are absent.
9. **Portable/no elevation** — CanvasExpert and MCP run from the unzipped folder with the
   current interpreter. No installer/CLI bootstrap, Program Files write, PATH/registry/
   firewall/service/scheduled-task mutation, process elevation, or client-config write was
   added. Optional ChatGPT tunnel absence does not degrade core MCP.

Use a secret/PII-oriented search over the diff, but do not print matching private values to
the terminal or handoff. Report only file/line locations and category. If a match might be
real data, stop immediately and tell the maintainer privately which tracked file requires
inspection.
