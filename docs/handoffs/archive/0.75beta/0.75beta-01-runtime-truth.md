## Locked design for this slice

### Runtime path service

Create `api/runtime_paths.py`. It is a small concrete resolver, not an environment
framework. Use `pathlib.Path` internally and return `str` only where an existing caller
requires it. It must expose these call-time functions:

```python
app_root() -> Path                     # the single unzipped CanvasExpert root
api_root() -> Path
python_executable() -> Path            # Path(sys.executable).resolve()
mcp_entrypoint() -> Path               # app_root/api/mcp_server/__main__.py
workspace_root() -> Path | None        # delegates to current workspace setting
workspace_folder(name: str) -> Path | None
exports_dir() -> Path                  # workspace Exports or existing local fallback
temp_dir() -> Path                     # api/temp; create-on-use stays with caller
content_folders(kind: str) -> list[Path]
ai_ta_dir() -> Path
rubric_folders() -> list[Path]
```

`content_folders` accepts only `quiz`, `assignment`, `page`, and `rubric`; reject an
unknown kind with `ValueError`. Preserve the current fallback order and directory names
from `deps.py`. Do not cache any workspace-derived result. `app_root`, `api_root`,
`python_executable`, and `mcp_entrypoint` may be stable.

Derive `app_root` and `mcp_entrypoint` from `__file__`, never the registry, current working
directory, PATH, an installer record, or a copied configuration value. The resolver must
not create files, install dependencies, or probe for elevation. `python_executable()` is
the exact interpreter already running CanvasExpert; do not substitute `py`, `python`, or a
PATH lookup.

Keep the public list functions in `deps.py` (`list_quiz_files`,
`list_assignment_files`, `list_page_files`, `list_rubric_files`,
`list_ai_ta_files`) as compatibility facades, but make each call the resolver. Replace
`_workspace_folder` and `_exports_dir` with thin function facades if callers still need
them. Remove `WORKSPACE_ROOT`, `QUIZ_FOLDERS`, `RUBRIC_FOLDERS`,
`ASSIGNMENT_FOLDERS`, `PAGE_FOLDERS`, and `AI_TA_DIR` constants.

Keep `TEMP_DIR` as the exact string compatibility facade
`str(runtime_paths.temp_dir())`. Remove the import-time `os.makedirs`; the existing
upload/download owner creates the directory immediately before its first write. Later
slices must not treat `TEMP_DIR` as workspace-derived.
