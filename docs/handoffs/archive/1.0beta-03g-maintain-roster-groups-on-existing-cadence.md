# Maintain private group context on the existing roster cadence

Status: **GREEN; completed**

Risk: **high** - group membership is private; an acquisition failure must not make stale membership appear current or change any Canvas mutation.

Depends on: current `dev` after `ea6b438`

## Teacher-visible result

Roster group context is refreshed by the existing daily roster/nightly full maintenance work,
so a teacher need not first open Roster to warm local group membership. Failed group refresh
is honest and does not fail the completed roster/full pass or affect live group writes.

## Acceptance criteria

- [ ] After a successful heartbeat `roster` or `full` pass, the service invokes the existing
  normalized `load_group_categories` owner once and writes the strict private groups snapshot
  with the heartbeat timestamp. It does not add a new cadence, pass name, or transport.
- [ ] Group loader/write failure leaves roster/full pass success intact, preserves last-good
  categories, marks the groups snapshot stale when one exists, and returns only a sanitized
  group-refresh status in that pass summary—never raw error text or private data.
- [ ] No group refresh occurs when the core roster/full pass fails, nor during ordinary delta.
  Concluded courses retain their existing full-only cadence.
- [ ] Group membership/category/group writes remain live-owned and unchanged. Roster route
  fallback behavior, snapshot allowlist/schema, browser assets, and manual Sync semantics do
  not change.
- [ ] The named acceptance gate below passes.

## Explicit non-goals

- No new coordinator, queue, scope registry, independent groups pass, Course Info migration,
  live transport rewrite, browser UI status, or group write reconciliation change.

## Locked decisions

- Reuse the existing `full`/`roster` cadence as the maintenance trigger. Report group work as
  nested evidence on that pass, not as a new global pass envelope.
- Keep `load_group_categories()` as the specialized live acquisition owner; inject it into
  the plain heartbeat function only as a test seam. Do not duplicate its 403 fallback.
- A successful normalized group result atomically replaces `groups.v1.json`; a failure marks
  an existing snapshot stale with a sanitized category, never persists raw text.
