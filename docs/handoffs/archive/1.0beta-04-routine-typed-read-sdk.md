# Give built-in and custom Routines a supported typed read interface

Status: **GREEN; completed** — commit `ae69f26`

Risk: **medium** - background reads may inspect private rows, but final mutation computation,
Canvas sends, receipts, and routine scheduling remain live and unchanged.

Depends on: commit `5bc929c` (accepted 03 report provenance and atomicity)

## Teacher-visible result

Read-only grading-debt/download discovery and newly authored custom read-only Routines reuse
current local assignments/roster/submissions with honest source/freshness, falling back live
when unavailable. Existing writing Routines retain their live decision boundary.

## Acceptance criteria

- [x] New `api/routine_reads.py::read_scope(...)` supports only `assignments|roster|submissions`
      and returns exact keys `ok, records, error, source, synced_at, generation`.
- [x] Current typed scope makes zero live calls; missing/stale/corrupt state uses the injected
      live reader with the existing endpoint/params and labels `source=canvas` without freshness
      or generation claims.
- [x] Built-in `grading_debt` and download assignment listing use `read_scope`; Student Reports
      remains on its report service. Sweep, curve, PowerGrader, and apply paths untouched.
- [x] Custom SDK injects `canvas_read`; `canvas_get`, `canvas_get_all`, `canvas_send` remain
      compatibility/live tools. Example and AUTHORING guide use `canvas_read`.
- [x] No private rows/source envelopes enter routine receipts, logs, fixtures, or configuration.
- [x] The named acceptance gate passes.

## Locked decisions

- One explicit mapping in `api/routine_reads.py`; unknown scope → structured error; no arbitrary URLs.
- The helper owns no Canvas import and no persistence. Callers inject `_canvas_get_all`; default
  age is `mirror_queries._serve_max_age_hours()` when omitted.
- Built-ins may ignore source metadata but must not serialize it. Custom authors receive the full
  result dict.
- Keep all live endpoint params exactly as `mirror_reads.py` currently defines them.
