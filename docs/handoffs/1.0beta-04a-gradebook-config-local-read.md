# Serve Gradebook config + roster display from the local read spine

Status: **READY**

Risk: **medium** - adds one new **student-free** late-policy display projection and routes two
pure-display reads through the local spine; every grade/policy WRITE stays live; no student
submission schema change.

Depends on: current `dev` after `c433410`. The gradebook grade snapshot is already
mirror-first with `source`/`synced_at` (`api/gradebook_snapshot.py:92-125`); this brief does
not touch it.

## Teacher-visible result

The Gradebook's **late-policy panel** and the **extra-time student list** render from
last-good local state (with visible freshness) instead of a live Canvas call on every load;
they still fall back to live when local data is missing/stale. Applying a late policy is
unchanged and live, and immediately refreshes the local policy so the panel is not stale after
a write. No grade/curve/sweep/extension behavior changes.

## Acceptance criteria

- [ ] A new **student-free** late-policy projection persists only the allowlisted Canvas
  `late_policy` fields (see Locked decisions), with unknown-key rejection, atomic write, a
  validated previous snapshot, and a `state`/`source`/`synced_at` envelope. No student data,
  tokens, URLs, or timestamps beyond `synced_at` are stored.
- [ ] `GET /api/late-policy` serves mirror-first: return the local projection with
  `source="mirror"` + `synced_at` when present and fresh; otherwise do the existing live
  `_canvas_get(.../late_policy)`, seed the projection, and return `source="canvas"`. The
  existing `404 -> {"policy": null}` and error behavior is preserved. (Acquire-on-read,
  mirroring `list_groups` in `api/webui/routes/courses.py`.)
- [ ] `POST /api/late-policy/apply` stays live (PATCH/POST per course, unchanged) and, after a
  verified success for a course, refreshes or invalidates **that course's** late-policy
  projection only. A reconcile failure leaves the scope stale, never falsely current.
- [ ] `GET /api/students/list` (extra-time UI) serves students from the roster mirror when its
  state is `current`, else the existing live `_course_students` call. Email is not included.
- [ ] No submission schema change (`cached_due_date`/`seconds_late` remain deferred to their
  consumer batch). No Canvas grading-period read is added. Assignment-group weights are not
  wired into Gradebook. Sweep-apply, curve, and extension write paths are untouched.
- [ ] The named acceptance gate below passes.

The executor reports evidence; it does not redefine, narrow, or self-accept these criteria.

## Explicit non-goals

- Do not add `cached_due_date`, `seconds_late`, or any personalized due/late field to the
  submission projection. Senior-deferred to Batch 4/5 (their real consumers live there).
- Do not add the late-policy projection to the **Course Catalog** contract (that needs a
  versioned catalog bump + validator change). Use a separate small student-free projection.
- Do not add a background cadence job for late policy; acquire-on-read is sufficient.
- Do not touch the gradebook grade snapshot, curve/sweep/extension paths, or `/api/sweep/*`.
  Sweep-apply's authoritative recompute (`operation_ledger/adapters/sweep.py`) is a regression
  boundary — do not weaken it.
- Do not add Canvas grading periods (the Gradebook uses local calendar CSV; no Canvas
  consumer exists). Do not commit.

## Locked decisions

- **Late-policy allowlist** (persist only these; reject unknown keys): `late_submission_deduction_enabled`,
  `late_submission_deduction`, `late_submission_interval`, `late_submission_minimum_percent_enabled`,
  `late_submission_minimum_percent`, `missing_submission_deduction_enabled`,
  `missing_submission_deduction`. Drop `id`, `course_id`, `created_at`, `updated_at`.
- **Acquire-on-read** pattern (mirror-first + live seed), copying `list_groups`; no new cadence.
- **Freshness convention** matches the grade snapshot: `source` ("mirror"|"canvas") and
  `synced_at` ("" when live) on the response.
- All late-policy **writes stay live**; local policy never authorizes an apply. Post-apply
  reconciliation is per-course and honest about failure.
- Extra-time student list reuses the existing roster mirror read; **no email** field.

### Deviations / design notes (not stop conditions)
- **No TTL on `late_policy_is_current`.** Unlike `groups_are_current` (24 h age check),
  freshness here is `state == "current"` only — matching `courses.py`'s `_local_students`
  precedent, not `groups_are_current`'s age policy. The brief locks "acquire-on-read,
  copying `list_groups`" (the branch structure) and "no new cadence," but does not lock a
  numeric TTL; since the only staleness trigger this slice needs is the post-apply
  invalidate (exercised by the named gate), inventing an untold TTL number seemed like
  unwarranted scope. Flagging this choice for senior review.
- **`gradebook_common._course_students` was not modified.** The brief's scope line names
  both `gradebook_extra_time.py` and `gradebook_common.py _course_students`; touching the
  shared alias directly would have silently made curve preview/apply, the grade snapshot,
  MCP tools, and the operation-ledger curve adapter mirror-first too — all explicitly
  out-of-scope/regression boundaries. Instead, a new `_roster_students_or_none` sits beside
  it in `gradebook_common.py`, and `gradebook_extra_time.py`'s route calls the existing
  `_course_students` only as the literal live fallback the acceptance criterion describes.
- **Live GET late-policy response is not scrubbed to the allowlist.** `get_late_policy`'s
  live-path JSON body returns Canvas's raw `late_policy` object (unchanged pre-existing
  behavior — the route never selected fields out of it before this slice); only the
  **persisted file** enforces the 7-field allowlist. The teacher-facing `policy.js` already
  only reads the 7 known fields, so this is a no-behavior-change carry-forward, not a new
  gap.
- Discovered en route: the repository working tree already carried unrelated, pre-existing
  uncommitted changes (`api/webui/routes/courses.py`, `api/webui/static/course_info.js`,
  `api/webui/templates/course.html`, `docs/handoffs/1.0beta-03i-course-info-local-spine.md`,
  `api/tests/test_course_info_routes.py`) from a different, apparently-uncommitted prior
  slice. Per AGENTS.md ("preserve unrelated worktree changes"), these were left untouched
  and are not part of this diff.
