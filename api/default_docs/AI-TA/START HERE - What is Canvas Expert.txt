# Canvas Expert — Explainer for Teachers

## What is Canvas Expert?
Canvas Expert is a free, locally-run app for Canvas instructors. It lets you
author course content (quizzes, assignments, pages, rubrics) by chatting with
an AI assistant, then push that content into one or more Canvas courses with a
few clicks — no manual Canvas form-filling. It also includes gradebook tools
(late-work policies, curves, extensions) and a downloader for student work.

The big idea: **you describe what you want to an AI, the AI writes a file in a
strict format, and Canvas Expert delivers it to Canvas correctly.** The strict
format is what makes it reliable — the AI and the push tool speak the same
language, so nothing gets lost in translation.

## The two halves

1. **The Forges (authoring + pushing content).** Each Forge is a specialized
   tool for one kind of Canvas content. You author with an AI, save the AI's
   output as a .txt file, then load it into Canvas Expert and push.
2. **Gradebook Expert (managing grades).** Tools that act on your live
   gradebook: course-wide late policies, late-work sweeps, grade curves, and
   per-student extensions (including extra-time students). Changes are
   previewed before anything is applied.

## The four Forges

- **QuizForge** — quizzes for Canvas New Quizzes. 12 question types (multiple
  choice, multiple answer, true/false, fill-in-the-blank, essay, file upload,
  matching, ordering, categorization, stimulus passages, and more). Every
  choice gets a rationale — students learn *why* each answer is right or
  wrong. Quizzes can be pushed live to Canvas, or compiled offline into a
  Canvas-importable ZIP plus printable DOCX/PDF documents (student copy, answer
  key, rationale sheet).
- **AssignmentForge** — Canvas assignments with submission settings, point
  values, and optional differentiation tiers. A tier is a scaffolded variant
  assigned automatically to students in a named Canvas group (the four product
  tiers: Support/Core/Accelerate/Extend) — one file, differentiated delivery.
- **PageForge** — Canvas content pages: unit hubs, resource collections,
  overviews. Rich HTML with callouts and links. Placeholders like
  {{file:Rubric.pdf}} resolve per course, so one page file works across all
  your sections.
- **RubricForge** — rubrics in three renderings from one file: a Canvas
  rubric attached to assignments, a student-friendly explainer page, and an
  AI scoring prompt so an assistant can score essays against the same
  criteria a human grader uses.

Each Forge has its own authoring contract (the exact file format). You never
need to learn the format yourself — the authoring skill files teach it to
your AI assistant.

## The AI-TA Library (this folder)
The folder this file lives in is a library of paste-ready "skills" — single
files you paste whole into MagicSchool, Copilot, or any AI chat:

- **START HERE** (this file): the overview.
- **Author a Quiz / an Assignment / a Page / a Rubric**: paste one in, then
  describe what you want; the AI converses with you and outputs a ready-to-
  push file.
- **Score with …**: one file per rubric in your rubric library. Paste one in,
  then paste a student essay; the AI scores it against that rubric with
  written feedback.
- **MagicSchool Toolkit**: setup and instruction files for building these as
  reusable custom tools in MagicSchool.ai instead of pasting each time.

## A typical workflow
1. **Author.** Paste an authoring skill (e.g. "Author a Quiz") into your AI
   chat and describe what you want — topic, grade level, rigor, standards.
2. **Save.** Copy the AI's final output and save it as a .txt file.
3. **Load & validate.** In Canvas Expert, open Course Expert, pick the
   matching tab (Quiz / Assignment / Page / Rubric), and load the file. It is
   validated and summarized before anything touches Canvas.
4. **Select courses.** Check every course/section that should receive it.
   Per-course details (modules, grading categories, groups) are matched by
   name, so one file works everywhere.
5. **Configure & push.** Set due dates, module placement, publish state, then
   push once. The log shows what happened in each course.

## Beyond pushing content
- **Download student work**: pull all submissions for an assignment to your
  computer in one go (handy for AI-assisted scoring or offline grading).
- **Quick assignment**: create a fast gradebook column without authoring a
  full file.
- **Gradebook Expert**: set a Canvas-native late policy, sweep late/missing
  work, apply curves with transparent math, and grant extensions — including
  managing your extra-time student list.
- **QuizForge offline**: quizzes also work with zero Canvas connection via
  the QuizForge web app — compile to an import ZIP and printable DOCX/PDF documents,
  then import into Canvas by hand.

## FAQ
**Q: Do I need to know how to code or write JSON?**
A: No. The AI writes the file; Canvas Expert reads it. You converse in plain
English and click buttons.

**Q: Is my Canvas login safe?**
A: Canvas Expert runs only on your own computer and talks directly to Canvas.
Your Canvas token is stored in your operating system's secure credential
store, never in a plain file, and is never sent anywhere except Canvas.

**Q: Can I push the same thing to several courses at once?**
A: Yes — that's the default design. Check the courses you want and push once.
Course-specific details are matched by name in each course.

**Q: Can I edit content after it's pushed?**
A: Yes. Everything lands as normal Canvas content — quizzes, assignments,
pages, and rubrics are all fully editable in Canvas afterward.

**Q: What's a "tier"?**
A: A differentiation variant. Assignments and quizzes can carry tiers that
auto-assign to students in named Canvas groups — same learning target,
different scaffolds, no separate copies to maintain.

**Q: What if validation fails or a push reports an error?**
A: Copy the error message back into your AI chat (with the authoring skill
still loaded) and ask it to fix the file. Then reload and try again.

**Q: Can it convert my old quizzes (PDF, DOCX, scans)?**
A: Yes — paste the text (or OCR output from a scan/photo) into your AI chat
with the "Author a Quiz" skill loaded and ask it to convert. Review the
result, especially after OCR, then push as usual.

**Q: Can the AI score essays for me?**
A: It can *assist*. The "Score with …" skills make your AI apply a specific
rubric consistently and explain its scores. You stay the grader of record —
review before entering grades.

**Q: Do the gradebook tools change grades without asking?**
A: No. Gradebook actions show you what will change before applying, and
curve adjustments include transparent math in the grade comments.

## Common pain points
- **File won't validate**: the AI's output drifted from the contract. Paste
  the validation error back to the AI and ask for a corrected file.
- **Friendly text around the output**: harmless — Canvas Expert reads only
  what's between the format tags and ignores chat text around it.
- **Names must match**: per-course matching (modules, groups, grading
  categories) is by name. If a course uses a different name, fix the name in
  Canvas or in the push options.
- **Be specific with the AI**: state grade level, rigor, question mix, and
  standards. Vague asks get generic content; review before pushing.
