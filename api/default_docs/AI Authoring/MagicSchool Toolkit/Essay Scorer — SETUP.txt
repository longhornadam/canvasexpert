MagicSchool Custom Tool: Essay Scorer
============================================================

Suggested Tool Name: Essay Scorer
Suggested Tool Description: Scores student essays using a rubric file attached as Knowledge.

Instructions (upload or paste):
  File: Essay Scorer — INSTRUCTIONS.txt
  (Upload this file in the Instructions field, or paste its entire contents.)

Knowledge file(s) to attach:
  - (your rubric .txt file from the Rubrics folder — e.g. ELA7_Classroom_Writing_Rubric.txt)
  (Attach these in the Knowledge section of the tool.)
  Note: MagicSchool field limits are ~75,000 words — far above any of our files.

Customize (suggested starting text):
  My students are [grade level] [subject].
  I want feedback language suitable for [audience: students / teacher].

Build steps:
  1. In MagicSchool: My Creations → + Create Tool → Configure.
  2. Enter the suggested Tool Name and Tool Description above.
  3. In Instructions: upload the instructions file (or paste it).
  4. In Knowledge: attach the knowledge file(s) listed above.
  5. In Customize: paste the suggested text above and adapt it.
  6. Save and Test — paste a sample request to confirm the output format.
  7. Share the tool with your co-workers.
