About this folder

This folder contains paste-ready single-file skills for MagicSchool.ai and
M365 Copilot. Paste one whole file into your chat assistant, then keep the
conversation inside that one file's instructions.

File categories:
- START HERE: Canvas Expert overview and how the system fits together.
- Authoring skills: one file each for QuizForge, AssignmentForge, PageForge, and RubricForge.
- Scoring skills: one file per valid rubric in the default rubric library.
- Reference: supporting material some authoring skills point to.
- MagicSchool Toolkit: setup recipes for building these as reusable custom tools in MagicSchool.ai.

Canvas Expert seeds missing files in this folder, then leaves existing files
alone so you can refine them by hand.
