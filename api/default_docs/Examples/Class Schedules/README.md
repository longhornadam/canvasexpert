# Class schedule examples

These are three complete class schedule sets for the Settings panel. Nothing in this folder
is copied into a workspace on first run. Settings copies one set only when a teacher asks for
it under Class schedule examples.

Every course name, bell time, and date here is invented. The seeded schedules in
`api/default_docs/Calendars/` are real, sanctioned public district times. Keeping these
examples invented makes the two sources easy to distinguish.
