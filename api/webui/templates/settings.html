Canvas account

Your Canvas API token gives Canvas Expert access to all your courses — paste it once here and you never need to touch it again. It's stored in your Windows Credential Manager (not in any file on disk).

In Canvas: Account → Settings → + New Access Token. Name it CanvasExpert – {{ computer_name }}, use no expiry unless your district requires one, copy it, and paste it here. Generate a fresh token on each computer; never reuse one or write it down. If a machine is lost, delete just that token from the same Canvas page.

AI assistance (OpenRouter)

PowerGrader can use OpenRouter to co-score submissions and draft feedback. The API key is stored in Windows Credential Manager; the selected model is stored locally on this computer.

Open API keys ↗ Open models ↗ Add credits ↗

OpenRouter is a paid API gateway for AI models. Canvas Expert sends only the pseudonymized grading bundle after its safety gate passes, then brings the score and feedback suggestion back for you to review.

  1. Create or sign in to an OpenRouter account.
  2. Go to API Keys, create a key named CanvasExpert - {{ computer_name }}, and optionally set a small credit limit.
  3. Add a small amount of credits before using paid models.
  4. Use DeepSeek V4 Pro ({{ default_openrouter_model }}) for routine grading.
  5. Use the searchable model field below for exact OpenRouter model IDs, including latest aliases.

    Add a custom CSV calendar

    Paste a calendar CSV. Two formats are accepted:
    Canonical (7 columns): school_year,row_type,code,name,start_date,end_date,report_issue_date,basis — row_type values Holiday, No School for Students, and Holiday for Students/Teachers become no-count dates; Academic Period rows become grading-period presets in the sweep.
    Simple (4 columns): Category,Name,Start Date,End Date — Student Day Off becomes no-count dates; Academic Period becomes grading-period presets. Dates can be MM/DD/YYYY or YYYY-MM-DD.

    Need a starting point? Download the blank template — then ask an LLM to fill it in for your district and year.
